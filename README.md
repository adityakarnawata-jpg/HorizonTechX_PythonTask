# HorizonTechX_PythonTask
Python programming task for HorizonTechX internship: Hangman, Stock portfolio tracker, and basic chatbot
Python programming tasks completed as part of the HorizonTechX internship.

# Projects

## Task 1 — Hangman Game
A command-line Hangman game where the user guesses a randomly selected word.

## Task 2 — Stock Portfolio Tracker
A command-line application that calculates stock portfolio value based on predefined stock prices and quantities.

## Task 4 — Basic Chatbot
A simple rule-based chatbot named PyBot that responds to predefined user inputs.

# Technologies Used
- Python 3
- VS Code
- CSV
- Python Standard Library

# How to Run
python task1_hangman.py
python task2_stock_tracker.py
python task4_chatbot.py
